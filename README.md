# Customer Feedback Analysis Using Python

## 📌 Project Overview

This project focuses on collecting, cleaning, and analyzing customer feedback using Python. It helps understand customer opinions, identify common feedback keywords, and evaluate customer satisfaction through ratings.

The project uses basic Python programming concepts and text-processing techniques to transform raw customer feedback into meaningful insights.

## 🎯 Project Objectives

- Collect and manage customer feedback.
- Allow users to add new feedback dynamically.
- Clean and preprocess text data.
- Identify frequently used words.
- Calculate the average customer rating.
- Find the longest customer feedback.
- Extract unique words from feedback.
- Sort customer feedback based on ratings.

## 🛠️ Technologies Used

- Python
- Jupyter Notebook
- Basic Data Structures (Lists, Dictionaries, Sets)
- String Manipulation
- Loops and Conditional Statements
- Python Functions
- Lambda Functions
- Sorting and Data Analysis

## 📊 Project Workflow

1. **Data Collection:** Create a sample dataset containing customer names, written feedback, and ratings.
2. **Adding Feedback:** Allow users to enter additional customer feedback through input functions.
3. **Data Cleaning:** Remove punctuation, convert text into lowercase, and remove unnecessary spaces.
4. **Word Analysis:** Count occurrences of specific keywords such as Good, Poor, and Excellent.
5. **Rating Analysis:** Calculate the average customer rating.
6. **Feedback Analysis:** Identify the longest feedback and extract unique words.
7. **Data Sorting:** Arrange customer feedback in descending order based on ratings.

## 📈 Key Analysis

The project generates the following insights:

- Keyword frequency analysis.
- Average customer rating.
- Longest customer feedback.
- Unique words in customer feedback.
- Customer feedback sorted by ratings.
